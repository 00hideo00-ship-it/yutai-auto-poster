# Privacy Policy — YutaiShorts

Last updated: 2026-11-15

YutaiShorts is a personal tool that posts short videos to the app owner's own
TikTok account through TikTok's official APIs.

## Data we handle
- TikTok OAuth tokens (access token and refresh token) for accounts that have
  authorized this app. They are stored only in the operator's private
  environment (local .env file or CI secrets) and are used solely to call
  TikTok's Content Posting API.
- The videos and captions generated by the tool, which contain only publicly
  available information about shareholder-benefit programs.

## What we do not do
- We do not collect TikTok user profile data beyond what the OAuth flow
  returns (open ID).
- We do not sell, rent, or share tokens or personal data with third parties.
- We do not track viewers or run advertising analytics.

## Revoking access
Authorization can be revoked at any time in the TikTok app:
Settings → Security and privacy → Apps and services → YutaiShorts → Remove.
Revoking access invalidates the stored tokens.
